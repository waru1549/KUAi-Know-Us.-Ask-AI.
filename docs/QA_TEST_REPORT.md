## 1. Automated tests (รันอัตโนมัติใน CI)

| ชุดทดสอบ | เครื่องมือ | ครอบคลุม |
|---|---|---|
| Frontend | Vitest + React Testing Library | หน้า Portfolio, หน้าแชต (ส่งข้อความ, Loading, error + Retry, ประวัติ), Component แชต, การเรียก API, สลับภาษา |
| Frontend | ESLint + `tsc -b` + `vite build` | คุณภาพโค้ด, type, build ผ่าน |
| Backend | Node.js test runner (`npm test`) | ตรวจ UUID, rate limit ต่อ IP, ข้อมูล Portfolio, context ที่ส่งให้ AI ไม่มี Placeholder และไม่มี secret |
| Backend | `tsc --noEmit --strict` | type ของ server, database, tests |

## 3. Bug ที่พบระหว่างทดสอบและการแก้ไข

| # | อาการ | สาเหตุ | การแก้ไข | สถานะ |
|---|---|---|---|---|
| 1 | ประวัติแชตหายเมื่อ server รีสตาร์ท | เก็บแชตไว้ในหน่วยความจำ (Map) ไม่ได้ใช้ฐานข้อมูล | ต่อ PostgreSQL: บันทึกด้วย transaction และอ่านประวัติจากตาราง `messages` | แก้แล้ว |
| 2 | AI ไม่รู้ทักษะของสมาชิก | ข้อมูลสมาชิกถูกตั้งเป็น Placeholder ทั้งก้อน | ส่ง role/skills/responsibilities ที่ยืนยันแล้วให้ AI และกรองเฉพาะข้อความ Placeholder | แก้แล้ว |
| 3 | AI ตอบคำถามทั่วไปนอกเรื่องทีม | System prompt อนุญาตให้ใช้ความรู้ทั่วไป | เขียน prompt ใหม่ให้ปฏิเสธเรื่องนอกทีม | แก้แล้ว |
| 4 | พื้นหลัง Galaxy ไม่แสดง | `body` มีพื้นหลังสีทึบบังเลเยอร์ `z-index: -1` | ตั้งพื้นหลัง `body` เป็นโปร่งใส | แก้แล้ว |
| 5 | Build พัง: ฟังก์ชัน `PortfolioPage` ซ้ำ | สคริปต์แก้ไขไฟล์จับ `</main>` ผิดตำแหน่ง | แก้ไฟล์ให้เหลือฟังก์ชันเดียว และ build ผ่าน | แก้แล้ว |
| 6 | รูปของไอซ์ไม่ขึ้น | ชื่อไฟล์ซ้อนนามสกุลเป็น `member-1.jpg.jpg` | เปลี่ยนชื่อไฟล์ และเพิ่ม unit test ตรวจรูปแบบ path ของรูป | แก้แล้ว |
| 7 | เว็บบน Vercel ขึ้น “Unable to load portfolio data” | ไม่มี backend บน production และเปิดผ่านลิงก์ deployment ที่ไม่อยู่ใน CORS | Deploy backend บน Render ตั้ง `VITE_API_BASE_URL` และ `CORS_ORIGINS` | แก้แล้ว |
| 8 | แชตบนเว็บจริงตอบ 403 | โปรเจกต์ Google ใช้ Gemini free tier กับรุ่นเดิมไม่ได้ (ยืนยันด้วยการยิง API ตรงจาก PowerShell) | เปลี่ยน `GEMINI_MODEL` เป็น `gemini-3.5-flash-lite` | แก้แล้ว |
| 9 | เมนู History อ่านยาก | ใช้พื้นโปร่งแสง ข้อความด้านหลังทะลุ | เปลี่ยนเป็นพื้นทึบ เพิ่มขนาดตัวอักษร | แก้แล้ว |
| 10 | คำตอบ AI แสดงเครื่องหมาย `*` และ `**` ดิบ (พบจากเคส C1) | Gemini ตอบเป็น Markdown แต่กล่องแชตแสดงเป็นข้อความธรรมดา | เพิ่ม component `RichText` แปลง bullet, ตัวเลข, ตัวหนา และ `code` เป็น element ของ React (ไม่ใช้ innerHTML จึงไม่เสี่ยง XSS) พร้อม unit test | แก้แล้ว |
| 11 | เมนูประวัติแชตบนมือถือล้นขอบจอซ้าย อ่านชื่อแชตไม่ได้ (พบจากเคส P7) | กล่องเมนูชิดขวาของปุ่ม แต่บนมือถือปุ่มอยู่ซ้ายสุด | ยึดกล่องกับความกว้างของ header: มือถือกว้างเต็มแถว จอใหญ่ชิดขวากว้าง 24rem | แก้แล้ว |
| 12 | ข้อมูลหน้าที่ของคนที่ 3 ไม่ตรงงานจริง (ระบุ Docker/Nginx ซึ่งโปรเจกต์ไม่ได้ใช้) และป้ายผลงานยังเป็น IN PROGRESS | ข้อมูลตั้งต้นเขียนไว้ก่อนเลือกวิธี deploy | แก้ Main contribution, ทักษะ และหน้าที่ให้ตรงกับ GitHub Actions, Render, Vercel, Supabase และเปลี่ยนสถานะโปรเจกต์เป็น completed (แสดงเป็น LIVE) | แก้แล้ว |
| 13 | ปุ่ม “ลบ” ของแชตล่างสุดใน History ถูกซ่อน ต้องเลื่อนลงถึงจะเห็น (พบจากเคส C10) | ปุ่มลบเป็นกล่องลอยใต้แถว แต่รายการมี `overflow` ตัดส่วนที่เกินออก | ย้ายปุ่ม “ลบ” มาไว้ในแถวเดียวกับปุ่ม ⋯ จึงเห็นทุกแถว | แก้แล้ว |
